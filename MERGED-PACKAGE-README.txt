APNAFINDS ALL-IN-ONE MERGED PACKAGE
===================================

This package merges:
1. ApnaFinds Premium OTP + Guest Checkout V9 complete project
2. Commerce Hub Premium Index + Admin Catalog overlay

Included upgrades:
- Premium modern homepage
- Admin Commerce Hub
- Supplier catalog import/export foundation
- Single and bulk product management
- Website / Amazon / Meesho / Flipkart channel sections
- Contextual WhatsApp support and social links from the V9 project
- Existing OTP, checkout, account, order, returns, logistics demo and admin features

IMPORTANT:
- Marketplace, Razorpay, Shiprocket and supplier APIs are foundations only until real approved API credentials and backend connectors are added.
- Never place API keys inside public HTML or JavaScript.
- Never upload .env to GitHub.

SAFE INSTALLATION INTO LIVE PROJECT:
Copy only the public folder from this package into your live project if your current live backend is already working.
Do not replace server.js, server/, package.json, package-lock.json, .env or data unless you deliberately want to replace the whole backend.
