APNAFINDS COMMERCE HUB - SAFE LIVE OVERLAY
==========================================

THIS PACKAGE REPLACES ONLY:
- public/index.html
- public/admin.html
- public/admin-commerce-hub.html
- public/admin-catalog.html
- public/js/catalog-manager.js

IT DOES NOT REPLACE:
- server.js
- server/
- package.json or package-lock.json
- .env
- data/
- OTP/authentication/payment/logistics code

WHAT IT ADDS:
- Premium modern lifestyle homepage
- One Commerce Hub dashboard with separate Website, Amazon, Meesho, Flipkart and supplier areas
- Catalog import/export foundation
- Single and bulk product management via CSV/JSON
- PDF catalog intake for manual review

IMPORTANT REALITY:
- Amazon, Meesho, Flipkart, payment gateway, Shiprocket and dropship suppliers are NOT live-connected by this frontend overlay.
- Real automation requires approved seller/API access and separate secure backend connectors.
- Do not paste API keys into HTML or JavaScript.

HOW TO APPLY:
1. Extract this ZIP.
2. Double-click APPLY-TO-LIVE.bat.
3. Press Enter to use the default live-project path, or paste the correct path.
4. Wait for all checks.
5. Review git diff --name-only.
6. Only when checks pass, commit with: git add public
